# Bird Classification API — Setup and Run Guide (Windows)

## Prerequisites

- Windows 10/11
- Visual Studio Code
- Internet connection for installing dependencies and downloading the pretrained model
- Python 3.12 (will be installed automatically by `uv` if needed)

### Step 1: Check whether `uv` is installed

Open **Command Prompt (CMD)** or **PowerShell** and run:

```powershell
uv --version
```

If the command returns a version number, proceed to Step 3.

If `uv` is not installed, proceed to Step 2.

### Step 2: Install `uv`

Open PowerShell and run:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

After installation, close and reopen your terminal. Verify the installation:

```powershell
uv --version
```

If Windows cannot find the command, check that the installation directory is included in your `PATH`.

### Step 3: Open the project in VS Code

Open the `bird-classification` project folder in Visual Studio Code.

Ensure that your project structure looks similar to this:

```text
bird-classification/
├── .venv/
├── backend/
│   └── app.py
```

The `.venv` directory will be created in Step 4. Your project may contain additional files.

Open a new terminal in VS Code using **Terminal → New Terminal**.

Ensure that the terminal is in the project root, `bird-classification`, before continuing.

### Step 4: Create the virtual environment

Run:

```powershell
uv venv --python 3.12
```

This creates a virtual environment named `.venv` using Python 3.12. If Python 3.12 is not already available, `uv` can download it.

### Step 5: Activate the virtual environment

```powershell
.venv\Scripts\Activate.ps1
```

After activation, your terminal should display `(.venv)` or `(bird-classification)`.

If PowerShell blocks activation because of its execution policy, you can skip manual activation and use the `uv run` commands in Step 7 instead.

### Step 6: Install the required Python packages

From the project root, run:

```powershell
uv pip install fastapi uvicorn torch torchvision transformers pillow python-multipart
```

These packages provide the API framework, ASGI server, pretrained model inference, image processing, and file upload support.

Note: PyTorch installation may take some time and requires a compatible package for your CPU or GPU environment.

### Step 7: Start the FastAPI backend

Change the working directory to `backend`:

```powershell
cd backend
```

Start the application:

```powershell
uv run --project .. python -m uvicorn app:app --host 0.0.0.0 --port 8000 --reload
```

The `--project ..` option tells `uv` to use the virtual environment in the parent project directory. This works whether or not the environment was manually activated.

Wait for the server to start. You should see a message similar to:

```text
INFO:     Uvicorn running on http://0.0.0.0:8000
INFO:     Application startup complete
```

On the first startup, the application may download the pretrained EfficientNet-B2 model from Hugging Face. Wait until the model has loaded successfully before sending requests.

**Important:** Keep this terminal open while using the API. Press `Ctrl+C` when you want to stop the server.

### Step 8: Open the interactive API documentation

Open your web browser and navigate to:

http://localhost:8000/docs

This opens the Swagger UI documentation generated by FastAPI.

### Step 9: Test the `POST /predict` endpoint

1. Locate and expand **POST `/predict`**.
2. Click **Try it out**.
3. Under the `file` field, click **Choose File**.
4. Select a bird image from your computer. Supported formats are JPEG, PNG, WEBP, and BMP.
5. Click **Execute**.
6. Review the HTTP response code and the JSON response body.

An example response is shown below. The values are illustrative and are not an actual model prediction.

```json
{
  "filename": "bird.jpg",
  "model": "dennisjooo/Birds-Classifier-EfficientNetB2",
  "predicted_class_id": 123,
  "predicted_class_name": "Example bird class",
  "confidence": 0.942135,
  "confidence_percent": 94.21
}
```

The response contains:

- `predicted_class_id`: the numeric class index assigned by the model.
- `predicted_class_name`: the corresponding class label from the model configuration.
- `confidence`: the predicted class's softmax probability, between 0 and 1.
- `confidence_percent`: the same value expressed as a percentage.

A high confidence score does not necessarily guarantee a correct species identification.

### Step 10: Check the API health

You can verify that the application is running by opening:

http://localhost:8000/health

A successful response should look similar to:

```json
{
  "status": "healthy",
  "model_loaded": true,
  "device": "cpu"
}
```

The device may be `cuda` if a compatible GPU is available and PyTorch is configured to use it.

### Troubleshooting

| Problem | Suggested action |
|---|---|
| `uv` is not recognized | Restart the terminal and verify the installation and `PATH`. |
| Python 3.12 is unavailable | Run `uv python install 3.12`, then retry Step 4. |
| `ModuleNotFoundError` | Ensure dependencies were installed into the project's `.venv`. |
| Port 8000 is already in use | Stop the other server or use a different port. |
| Model download fails | Check internet connectivity and Hugging Face availability. |
| `model_loaded` is false | Review the backend terminal for model-loading errors. |
| HTTP 415 | Upload a supported image format. |
| HTTP 400 | Check that the uploaded file is a valid image. |
| HTTP 500 | Review the backend terminal for the inference error. |

**Note:** The API currently classifies the entire uploaded image. If an image contains several birds, it returns one top prediction for the whole image rather than identifying each bird individually.
